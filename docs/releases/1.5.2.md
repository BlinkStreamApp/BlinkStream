# BlinkStream 1.5.2 — Session chat search

## ES

- Búsqueda en el chat nativo individual y unificado por texto, usuario, enlaces y canal de origen.
- Filtros combinables que respetan las pestañas y borrados de moderación, sin cambiar el destino de envío.
- Búsqueda limitada a los mensajes conservados en memoria de la sesión; se limpia al cambiar de cuenta o canales.
- Panel adaptable, cierre con Escape y traducciones en los ocho idiomas. Cambiar de idioma conserva filtros, borrador y conexión.
- Avisos Store con acceso traducido a las fuentes del runtime, sin duplicar el paquete compartido.
- Retirado del actualizador el extractor ZIP heredado que no utilizamos, eliminando la dependencia afectada por los avisos RustSec de extracción. Se conservan EXE, AppImage, TAR.GZ de macOS y la verificación de firmas.

## EN

- Search individual and unified native chat by text, sender, links and source channel.
- Combined filters respect chat tabs and moderation deletions without changing the send destination.
- Search only covers retained in-memory session messages and resets on account or source-channel changes.
- Responsive panel, Escape to close and all eight interface languages. Language changes preserve filters, drafts and the connection.
- Store notices provide localized access to runtime sources without duplicating the shared companion.
- Removed the unused legacy ZIP updater extractor and its dependency affected by RustSec extraction advisories. EXE, AppImage, macOS TAR.GZ and signature verification remain supported.

GitHub installers and Microsoft Store are separate distribution channels. The maintainer
uploads the MSIX to Store; this GitHub release does not publish a Store update.
