# BlinkStream 1.5.3 — Authentication security

## ES

- Handoffs OAuth privados, de un solo uso y con caducidad comprobada en el servidor.
- Identidad de Twitch validada con el identificador inmutable del usuario y la aplicación autorizada. Vinculación de cuentas antiguas con prueba de la sesión anterior.
- Validación del token al iniciar y cada hora; las sesiones revocadas se limpian automáticamente.
- Cerrar sesión revoca el token de Twitch y las sesiones Supabase accesibles antes de eliminar las credenciales locales. Sin conexión, la limpieza local se mantiene.
- Refresh exclusivamente por POST y retirada de dos permisos OAuth innecesarios.
- Actualizadas tres dependencias TLS para corregir la confianza en certificados intermedios retirados (RUSTSEC-2026-0381/0382/0383).
- Acerca de incluye APX Studio, web oficial y soporte en los ocho idiomas.

## EN

- Private, single-use OAuth handoffs with server-enforced expiry.
- Twitch identity checked against its immutable user ID and the authorized application. Legacy-account linking requires previous-session proof.
- Token validation at startup and hourly; revoked sessions are cleared automatically.
- Sign-out revokes the Twitch token and available Supabase sessions while removing local credentials. Local cleanup also works offline.
- POST-only refresh and removal of two unnecessary OAuth permissions.
- Updated three TLS dependencies to correct trust in distrusted intermediate certificates (RUSTSEC-2026-0381/0382/0383).
- About includes APX Studio, the official website and support in all eight languages.

GitHub installers and Microsoft Store use separate distribution channels. This
GitHub release does not submit an update to Microsoft Store. The Store runtime
is unchanged; its source companions remain available in release 1.5.0.
Updater signatures do not imply Authenticode signing or Apple notarization.
